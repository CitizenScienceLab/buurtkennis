{%- comment -%} Eén doosje per traject per buurt. Het script legt ze binnen de buurt zonder overlap; hier staan ze voorlopig op het midden van de buurt. Met midden: [x, y] in het trajectbestand zet je het eerste vast. {%- endcomment -%} {%- for t in site.trajecten -%} {%- for bs in t.buurten -%} {%- assign b = site.buurten | where: "slug", bs | first -%} {%- if b -%} {%- assign p = site.data.cbs[b.plek] -%} {%- assign x = p.midden[0] | default: 500 -%}{%- assign y = p.midden[1] | default: 500 -%} {%- assign vast = false -%} {%- if t.midden and forloop.first %}{% assign x = t.midden[0] %}{% assign y = t.midden[1] %}{% assign vast = true %}{% endif -%} {%- endif -%} {%- endfor -%} {%- endfor -%}
